# Vibe Player

A complete Kotlin + Jetpack Compose Android music player scaffold inspired by Spotify.

## Tech stack
- Material 3 Compose UI with dark mode, glassmorphism, rounded cards, smooth transitions, and dynamic-feeling green accents
- MVVM with Hilt dependency injection
- Media3 ExoPlayer and MediaSession background playback with notification/lock-screen controls
- Room database for songs, favorites, playlists, and recently played data
- Coil album artwork loading

## Features
Scans local MP3 files from device storage and provides Home, Search, Library, Settings, mini player, full player, favorites, recent plays, albums, artists, playlists, shuffle, repeat, next/previous, play/pause, and a waveform-style seek bar.
